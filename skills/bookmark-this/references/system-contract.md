# Bookmark system contract

## Default hierarchy

```text
<root>/
├── .bookmark-system/
│   └── config.json
├── index.md
├── bookmarks/
├── collections/
├── visualizer/              # optional
│   └── index.html
└── views/
    ├── categories/
    └── tags/
```

Bookmark files stay in `bookmarks/` by default. Categories, tags, and collections provide the navigable hierarchy without forcing file moves when the taxonomy changes.

## Configuration schema

Write valid UTF-8 JSON. Required keys are shown below.

```json
{
  "version": 1,
  "owner_label": "you",
  "agentic_platform": "codex",
  "source_bookmark_paths": [],
  "timezone": "Europe/Rome",
  "link_style": "markdown",
  "paths": {
    "bookmarks": "bookmarks",
    "views": "views",
    "collections": "collections",
    "index": "index.md"
  },
  "categories": [
    {
      "slug": "research",
      "label": "Research",
      "description": "Sources and material to investigate"
    }
  ],
  "capture": {
    "depth": "standard",
    "personal_relevance": "always",
    "inference_label": "Inference, not confirmed:",
    "retain_safe_original_url": false,
    "strip_tracking_parameters": true
  },
  "navigation": {
    "generate_category_views": true,
    "generate_tag_views": true
  },
  "visualizer": {
    "enabled": true,
    "path": "visualizer/index.html"
  }
}
```

## Allowed values

- `link_style`: `markdown` or `wikilink`
- `agentic_platform`: a lowercase platform label such as `codex`, `claude`, `hermes`, `openclaw`, `other`, or `none`
- `source_bookmark_paths`: zero or more absolute source folders approved by the user; these are inventory inputs, not automatic deletion or move targets
- `capture.depth`: `quick`, `standard`, or `deep`
- `capture.personal_relevance`: `always`, `on-request`, or `never`
- category and tag slugs: lowercase letters, digits, and hyphens
- paths: relative to the root; do not use `..`
- `visualizer.enabled`: `true` or `false`
- `visualizer.path`: a relative `.html` path inside the root

Unknown keys may be preserved for forward compatibility. Never put API keys, cookies, credentials, private tokens, or full conversation history in the configuration.

## Generated-file rule

Generated navigation begins with:

```markdown
<!-- generated by bookmark-this; do not edit -->
```

The rebuild script may replace only files with that marker. It must not overwrite an unmarked index or view file; resolve the collision with the user.

## Existing systems

When a root already contains notes:

- inventory matching Markdown files before setup;
- preserve existing files and links;
- choose a non-conflicting root or paths;
- migrate only after the user accepts a mapping;
- leave source files in place unless the user explicitly asks to move them.
