# Code of Conduct

## Our Pledge

We want Bookmark This to be a constructive and welcoming place to collaborate. Contributors, maintainers, and participants are expected to treat each other with respect and keep discussions focused on improving the work.

## Expected Behavior

- Be respectful in disagreement.
- Give specific, actionable feedback.
- Respect different experience levels and working styles.
- Protect other people's private information and bookmark data.
- Keep discussions relevant to the repository.

## Unacceptable Behavior

- Harassment, intimidation, discrimination, or personal attacks
- Deliberate disruption, trolling, or bad-faith argument
- Publishing private information without permission
- Sharing bookmark libraries, tokens, browsing data, or credentials that are not yours to publish
- Conduct that makes collaboration unsafe or needlessly hostile

## Scope And Enforcement

This code applies to repository issues, pull requests, discussions, and other project spaces. Maintainers may remove or reject contributions that violate it. Repeated or severe violations may result in exclusion from the project.

Report concerns privately to the repository owner through an appropriate GitHub contact channel. Include enough context for the issue to be evaluated fairly.
